Hướng dẫn khắc phục lỗi #ERROR! và cập nhật Webhook Google Sheets
💡 Nguyên nhân lỗi #ERROR!: Do Google Sheets cài đặt khu vực Việt Nam yêu cầu dấu phân cách trong công thức là dấu chấm phẩy (;) thay vì dấu phẩy (,). Script mới đã tự động nhận diện và sửa 100% vấn đề này!

Bước 1: Mở file Google Sheet qua nút Mở Sheet ở trên.

Bước 2: Vào menu Tiện ích mở rộng (Extensions) → chọn Apps Script.

Bước 3: Xóa sạch code trong file Code.gs, dán toàn bộ mã mới từ file google_sheets_script.gs vào và nhấn Ctrl + S.

Bước 4: Bấm Triển khai (Deploy) → chọn Quản lý bản triển khai (Manage deployments) → Bấm biểu tượng ✏️ (Chỉnh sửa) → Mục Phiên bản (Version) chọn Phiên bản mới (New version) → Bấm Triển khai (Deploy).

Bước 5: Bấm nút Đẩy Lên Google Sheet ở trên để cập nhật dữ liệu hoàn hảo không còn lỗi!
